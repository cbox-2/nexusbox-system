📖 توثيق API

استخدم المفتاح أعلاه للوصول إلى API:

Authorization: Bearer YOUR_API_KEY

Endpoints متاحة:

  • GET /api/boxes - جلب الصناديق
  • POST /api/boxes/:id/messages - إرسال رسالة
  • GET /api/boxes/:id/users - جلب المستخدمين
  • POST /api/boxes/:id/bans - حظر مستخدم
