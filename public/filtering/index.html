Filtering

Cbox supports filtering the text in messages and names posted to your NexusBox. You can use filters to hide objectionable content, or to create shortcuts, styled words, custom boxcode, and much more.

Built-in profanity filter

The built-in filter will mask out some common curse words. Use custom filtering to extend it.

Custom filtering

Each line is a filter. The format is word:replacement. Use !part:replacement to match substrings. If replacement is omitted, it defaults to asterisks. Boxcode is supported.
