Message webhook

Configure and enable the NexusBox webhook here. This allows you to receive a copy of every message published to your NexusBox at your own HTTP endpoint. This allows you to keep logs, trigger your own notifications, implement bots, and more.

This feature requires some development experience. See webhook help.

Webhook is a NexusBox Pro feature. Find out more about webhooks here.
